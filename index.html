// server.js — 핵심 스트리밍 루프
res.setHeader('Content-Type','text/event-stream');
const stream = client.messages.stream({
  model: 'claude-opus-4-7',
  system: [{ type:'text', text: SYSTEM_PROMPT,
             cache_control:{type:'ephemeral'} }],
  messages:[{ role:'user', content: userText }]
});
stream.on('text', t =>
  res.write(`data: ${JSON.stringify({t})}\n\n`));
stream.on('end', () => res.end());

문제 ②

API 크레딧 소모

증상 테스트 중 반복 호출로 비용 급증.
해결 IP당 10req/60s 레이트 리미터를 Map 기반으로 직접 구현 + 주기적 GC.

문제 ③

입력값 그대로 노출

증상 사용자 입력이 프롬프트·DOM에 무검증 진입.
해결 sanitize 함수로 < > 제거 · 최대 길이 제한 · 타입 검사 공통화.

기본소양 · 성능 최적화 +1
PERFORMANCE

성능 최적화

Prompt Caching

시스템 프롬프트에 cache_control: ephemeral 적용 → 반복 호출 시 입력 토큰 처리 비용·지연 절감.

30s → 3s

SSE 스트리밍으로 첫 출력까지의 체감 대기 시간 단축. 첨삭 1건 완료 30초 이내 목표 달성.

50kb 제한

express.json limit + 입력 5,000자 컷으로 서버 메모리·토큰 비용 상한 고정. 공유 저장소는 24h TTL 자동 정리.
